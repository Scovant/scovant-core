# Security policy

Scovant Core fetches arbitrary public URLs, so SSRF and resource-exhaustion
issues are treated as high severity.

## Reporting a vulnerability

Email security@scovant.com, or use GitHub's private vulnerability reporting
on this repository. Please include a reproduction. We acknowledge reports
within 3 business days and aim to release a fix within 30 days for high
severity issues. Do not open public issues for security reports.

## Scope

The scanner library and its parsers. Scovant Cloud (scovant.com)
has its own policy at https://scovant.com/policies.
